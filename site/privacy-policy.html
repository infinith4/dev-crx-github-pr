GitHub PR Comment Tools

Privacy Policy

最終更新日: 2026年5月4日  |  Last updated: May 4, 2026

GitHub PR Comment Tools（以下「本拡張機能」）は、GitHub の Pull Request ページ上で折りたたまれたレビューコメントを展開し、レビュースレッドの resolve / unresolve 操作を提供します。 本ページは、本拡張機能がどのようなデータを扱うかを説明します。

収集・保存するデータ

本拡張機能がお使いのブラウザの chrome.storage.local に保存するデータは以下のみです。

データ 内容 保存場所
ユーザー設定 コメント自動展開のオン/オフ、resolve/unresolve 操作の有効化、 解決済み・旧バージョンスレッドの表示設定、GitHub Enterprise ホスト一覧 chrome.storage.local（ブラウザ内のみ）
GitHub Personal Access Token resolve / unresolve 機能を有効にした場合のみ保存。 GitHub GraphQL API の呼び出しに使用。 chrome.storage.local（ブラウザ内のみ）
これらのデータはお使いのデバイス上にのみ保存されます。 本拡張機能の開発者・運営者のサーバーには一切送信されません。

データの利用目的

  • ユーザー設定: GitHub の PR ページを開いたとき、設定を読み込んでコメント展開の動作を制御するために使用します。
  • GitHub Personal Access Token: resolve / unresolve ボタンが押されたとき、GitHub GraphQL API（https://api.github.com/graphql）の呼び出しにのみ使用します。トークンは GitHub の API 以外に送信されることはありません。

収集しないデータ

  • 閲覧履歴・URL・ページの内容
  • 氏名・メールアドレスなどの個人情報
  • クリック・スクロールなどの行動データ（アナリティクス）
  • クラッシュレポート・エラーログ

第三者へのデータ提供

本拡張機能は、ユーザーのデータを第三者に販売・提供・共有することはありません。 GitHub GraphQL API への通信は、ユーザーが resolve / unresolve 操作を実行したときのみ発生し、 送信先は https://api.github.com に限定されます。

リモートコード

本拡張機能はリモートコード（外部 CDN からの JS 読み込み、eval() の使用など）を使用しません。 すべての JavaScript はビルド時にパッケージ内にバンドルされています。

データの削除

以下の方法でいつでも保存データを削除できます。

  • 本拡張機能をアンインストールする
  • Chrome の設定 → プライバシーとセキュリティ → サイトデータを削除 → 拡張機能のストレージをクリアする
  • Options ページでトークンを空欄にして保存する（トークンのみ削除）

本ポリシーの変更

本ポリシーを変更する場合は、このページを更新します。 重要な変更がある場合は、拡張機能のバージョンノートでお知らせします。
