GitHub PR のレビューをもっとスムーズに

折りたたまれたレビューコメントをワンクリックで展開。
resolve / unresolve 操作をページから離れずに実行。

GitHub で見る プライバシーポリシー

機能

💬 コメント展開 No token

「N 件の非表示のコメント」を自動または手動で展開。解決済み・旧バージョンのスレッドも表示対象に含められます。

✅ Resolve / Unresolve

レビュースレッドをページから離れずに resolve / unresolve。一括操作にも対応しています。

🏢 GitHub Enterprise 対応

github.com に加え、GitHub Enterprise Server のホストも設定できます。

🔒 プライバシー重視

すべてのデータはブラウザの chrome.storage.local に保存。外部サーバーへの送信はありません。

使い方

1

拡張機能をインストール

Chrome Web Store からインストールします。

2

GitHub の PR ページを開く

https://github.com/*/pull/* のページで自動的に動作します。コメント展開にトークンは不要です。

3

（任意）Resolve 操作を有効化

Options ページで GitHub Personal Access Token を登録すると、resolve / unresolve ボタンが有効になります。必要な権限は Pull requests: Read and write のみです。

データはブラウザ内にのみ保存されます

本拡張機能は収集したデータを外部に送信しません。GitHub トークンを含むすべての設定は chrome.storage.local に保存されます。 詳しくは プライバシーポリシー をご覧ください。
