Resolve / Unresolve

Comment expansion does not require a token. A token is required only when Resolve / Unresolve controls are enabled.

Recommended token: GitHub Fine-grained personal access token with access limited to the target repositories.

  • Repository permission: Pull requests: Read and write
  • Classic token fallback: use the repo scope only when a fine-grained token is not practical.
